# Real-Time E-Commerce Flash Sale & Order Tracker

A full-stack real-time e-commerce flash sale and order tracking application built with **FastAPI** (Backend) and **React + Vite** (Frontend).

## 🚀 Tech Stack
* **Backend:** Python, FastAPI, Uvicorn
* **Frontend:** React, Vite, JavaScript
* **Version Control:** Git & GitHub
